- 不可变来源、引用定位、重复导入和版本更新。
- URL 授权与 SSRF、路径访问、大小/时间预算、解析失败和重试。

- MCP 只读/写入开关、资源桥接、管理页查询和本地 HTTP 访问。

真实 Codex 已验证工具调用、扫描页图片读取、插件工作台与固定入口。
扫描页功能检查使用自制图片，不是 OCR 准确率基准。
