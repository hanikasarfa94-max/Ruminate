# 当前功能范围

版本 0.5.2 / schema 5，更新于 2026-11-16。测试与平台记录见 [EVALUATION.md](EVALUATION.md) 和 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 管理页与资料

- 已支持想法、资料、输出的搜索、筛选、分页和引用回看，每页 25 条。主题选择最多 50 项；改名、重新归类、归档、删除影响预览和批量管理待实现。
- 导入支持 PDF、Markdown、TXT 和 HTML。DOCX、独立图片、区域裁剪及批量视觉处理待实现。缺少标题元数据的 PDF 使用文件名显示。
- 扫描 PDF 可按需交给 Codex 阅读页图。视觉笔记使用 `host_model / unverified`，与原生文字分开保存。页图最长边 1800 像素、PNG 上限 8 MiB；大页面会降低分辨率。
- 检索使用英文词项、中文 n-gram 和 BM25，默认查询当前版本。语义搜索、作者和日期筛选待实现；旧引用通过 `version_id` 读取。
- Markdown 下载使用客户端能力，未提供下载接口时可复制全文。包含原件的导出使用 CLI export 或备份。

## 反刍与输出

- 本地调度根据已有关系、到期时间和反馈选择问题。`possible_conflict` 需要已确认观点、显式质疑关系及引用；自然语言矛盾识别待实现。
- `review list` 预览队列，`review present` 记录推荐曝光并执行每日三条及主题/来源限频。管理页的“待回看”列出全部到期想法。每次 tick 最多检查 500 条主张，可通过主题缩小范围。
- 已生成的候选保留当时的证据快照和评分。新增证据可从主张详情查看；更新提纲时生成新修订，保留历史版本。
- 自动反刍由 Codex Scheduled 触发，需要在使用者的客户端配置。内核提供存储与工作流；独立云模型客户端和订阅 API 待实现。
- 本地输出提供五类提纲模板，每版最多 50 条主张、200 处引用和 20 万字符证据快照。正文扩写由当前 AI 会话完成。资料观点、模型推断、假设和用户确认观点分别记录。
- enrichment 接口最多读取 20 个块并受字符预算约束，保存最多五条待处理提议。内置 NoLLM 用于本地整理，Mock 用于测试；自定义 Provider 的取消依赖异步协作。

## 运行与数据

- 已完成 macOS arm64 实测。文件导入依赖 POSIX；Linux 待验证，Windows 尚未提供对应实现。
- URL 导入支持公开 HTTP/HTTPS 默认端口；HTML 以静态内容解析。登录页面、动态页面、代理及压缩响应暂不支持。网络与文件校验规则见 [SECURITY.md](SECURITY.md)。
- 解析和页图渲染使用时间、CPU、输出与 RSS 预算。macOS 的 RSS 采样用于资源监测；它与操作系统内存隔离的范围不同。
- 备份为本地 ZIP，包含数据库快照、引用原件和已存输出。恢复写入新目录，支持最多 10000 个条目、512 MiB 展开总量、256 MiB 数据库、20 MiB 单个原件和 128 MiB 结构化记录。大型库和跨平台恢复待验证。
- SQLite 读取可能创建 WAL/SHM 协调文件。任务同步执行，自动重试和独立常驻 worker 待实现。
- 发送给 Codex / ChatGPT 的片段和页图进入该会话上下文。本地资料与配置保存在 Git 忽略目录。项目采用 Apache License 2.0，导入内容保留各自权利。

## 验收范围

自动化检查覆盖应用服务、CLI、MCP 协议和浏览器交互。原生插件工作台及固定入口已通过人工验收；完整原生桌面点击流程、ChatGPT Web 自定义 MCP、Tunnel 和 SIWC 待验证。

公开资料验收已覆盖行业报道、论文、工程文章和协议文档。历史笔记、独立实验材料和研究效果评估仍需补充。1000 篇 / 10 万块测量使用合成资料，范围为存储、索引、查询和定位。
