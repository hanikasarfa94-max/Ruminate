# Roadmap

Ruminate is a local research workspace that uses the existing AI host for reading
and reasoning. The next changes should make the evidence workflow easier to use
before expanding into more services.

## Available

- Local source import, immutable versions, exact locators and full-text search.
- Claims and evidence links, review feedback, cited drafts and backup/restore.
- CLI, stdio MCP, four skills and an embedded Ideas / Sources / Outputs workspace.
- Page rendering for host vision and a workflow for scheduled review suggestions.

## Next

- Improve topic naming, reassignment and source metadata editing.
- Add archive/delete impact previews that preserve historical citations.
- Validate fresh installations on more supported host and operating-system versions.
- Improve source selection and duplicate handling in review suggestions.
- Evaluate usefulness with a small annotated research collection and human feedback.

## Later, when the core workflow supports them

- Batch imports, independent images, DOCX and better complex-document parsing.
- Optional source connectors, RSS and one-way exports.
- Optional semantic retrieval and explicitly configured model providers.

The project does not include a second chat system, automatic access to host chat
history, or a required cloud database. This is a direction, not a dated delivery
commitment. See [known limitations](KNOWN_LIMITATIONS.md) for current details.
