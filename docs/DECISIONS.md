# 技术决策

## 本地内核与宿主分工

CLI、MCP 与页面共享 Application。SQLite WAL/FTS5 保存结构化知识，SHA256 文件仓
保存原始字节。原件、版本、块与输出修订保留历史。Ruminate 无需模型凭据即可完成
导入、检索、引用、队列和模板输出；阅读与推理由使用者已有的 AI 宿主承担。

## 导入与证据

- pypdf 负责原生 PDF 文字；pypdfium2 + Pillow 负责按需页图渲染。
- HTML 使用 trafilatura 解析已取得的字节；解析器不自行抓取附件。
- URL 请求使用标准库与固定验证过的 IP，保留 TLS 主机名验证和逐跳授权检查。
- 本地文件使用 POSIX 目录句柄和 no-follow 访问；暂不提供 Windows 等价实现。
- 中文使用索引侧单字/双字 n-gram，原文不因分词而改写。
- 精确片段校验验证引用位置；来源主张、模型推断、假设和明确确认的用户观点分开保存。

## 反刍与输出

预览队列和记录曝光分开。候选根据证据关系、到期时间和反馈评分，保留理由与来源；
主动展示每天最多三条。管理页可阅读全部到期待回看事项。

输出先组织已有主张与引用，扩写由宿主对话完成。每版保存快照并核对引用。
新 Markdown 使用 format 2，format 1 保留原始渲染规则，旧修订不会因文案变化失效。

## 界面与安装

主要入口为 MCP Apps，页面通过宿主桥读写同一资料库，选中内容可关联到当前对话。
UI 不保存第二套聊天历史，也不直接连接 localhost。HTTP 适配器只用于可选本地预览。
本地插件注册文件由安装脚本生成，保留在 Git 忽略目录。
