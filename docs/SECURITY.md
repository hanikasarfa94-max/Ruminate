## 授权与文件访问

CLI 显式文件参数只授权该文件；Python API 必须提供 Config 文件/目录 scopes。授权对象的文件或目录类型在配置时固定，不能把获准文件换成目录后扩大范围。目录内路径解析后必须仍落在授权范围；最终读取通过 POSIX 目录句柄、`O_NOFOLLOW` 和普通文件检查，拒绝硬链接、特殊文件、读取中发生变化的文件及超限内容。

CAS 路径仅从 SHA256 派生，读取校验内容 hash；blob 原子写入，不跟随被替换的派生目录链接。数据库及 WAL/SHM 等派生路径同样检查。当前安全文件 I/O 使用 POSIX API，Windows 返回 `secure_io_unavailable`，该平台暂不提供此导入方式。

数据目录必须由用户控制。上述检查不等于抵御拥有相同用户权限、能任意改写整个工作区或应用代码的攻击者。新建目录 0700、数据库与 blobs 0600；不自动收紧已有父目录权限。

## URL 抓取

- `ask` 需要本次显式授权，`off` 拒绝网络，`allowlist` 对每跳检查精确主机名。
- 仅默认端口的 HTTP/HTTPS；拒绝 URL 凭据、私网/loopback/link-local/metadata 地址、非全局地址及 IPv6 过渡地址。
- DNS 所有返回地址都必须通过校验，实际 socket 连接固定其中一个已验证数值 IP，TLS 仍验证原域名；重定向重新检查 DNS 和授权，HTTPS 不降级为 HTTP。
- 不读取代理环境变量，不发送 cookie、凭据或自动执行浏览器脚本。
- 默认总时限 10 秒、最多 5 跳、下载 20 MiB；请求 identity 编码并拒绝压缩响应，避免自动解压炸弹。Content-Type 保留 charset，但元数据长度和控制字符受限。
- DNS 缺少标准取消接口，最多 8 个 daemon resolver 可在请求超时后短暂继续等待；调用方等待有截止时间。真实 socketpair 测试覆盖慢响应头和正文中断。

## 不可信内容与解析预算

源文本只作为数据保存；网页指令、PDF 内容、代码围栏和链接不会授予权限或执行命令。HTML 解析不抓取 DTD、图片、脚本和样式链接。MCP 返回明确的不可信来源标记；带引用只说明来源如此陈述，不表示结论已核验。

默认输入上限 20 MiB、PDF 500 页；解析文本最多 200 万字符、单块 5000 字符、最多 10000 块。PDF/HTML 使用子进程 wall timeout 与 CPU 限制，文本解析使用线性处理及协作 deadline。pypdf 7 的解码器在内容流返回前执行 16 MiB 输出预算，不依靠“解压完再检查”。

macOS 本次无法启用 RLIMIT_AS，结果中保留 `parser_os_memory_limit_unavailable`；采用父进程超时、CPU 限制、25ms RSS 采样与解码预算组合。RSS 采样是观测限额，不是严格的瞬时内存上界。解析状态和警告记录扫描页、复杂布局、公式及图片的提取情况。

## 页面图像与宿主记录

页面工具只接受入库 source_id / version_id 和真实页码，不接受任意文件路径、密码或 URL。读取时验证原始 blob 的 SHA256；pypdfium2 在单次子进程内渲染，不初始化表单环境、不调用 JavaScript 或模型。每次一页、最长边 1800 像素、PNG 最多 8 MiB，并设置 wall / CPU / RSS 预算。进程隔离用于故障和资源控制，不等于操作系统安全沙箱。

返回的图像属于不可信来源数据；图中文字不能授予权限。MCP 返回图像本身和版本、页码、来源/图像 hash；CLI 导出只创建明确指定的新 PNG，拒绝覆盖已有路径。识别发生在现有宿主上下文，Ruminate 不自行上传文件或另接模型 API。

视觉转写与解读通过 CLI / Application 显式保存，要求 source_id、version_id、页码和幂等 request_id。记录固定为 host_model / unverified；调用方填写的 host 不证明模型身份，页级引用不证明转写准确。记录与审计原子提交，不覆盖原文、不加入原生全文索引、不推断用户观点，MCP 提供视觉记录的读取与显式保存接口。

## 数据、日志与只读语义

数据库先验证应用身份、必要 schema 和迁移 checksum；拒绝接管已有非空外部数据库，迁移失败整批回滚。任务失败只记录稳定错误码，审计记录存 ID、版本及去重状态，不写入来源正文或网络凭据。

MCP 默认提供九个只读工具：health_check、search_sources、get_source、get_source_page_image、list_visual_observations、get_claim、list_review_queue、get_topic_context、list_output_projects。它们不修改业务记录或原始文件；读取 WAL 数据库可能创建 `-wal` / `-shm` 协调文件，这不代表应用写入新业务数据。只读验收比较业务记录与原始文件；保留活跃 WAL/SHM 文件以保证数据库一致性。未初始化健康查询仍不创建目录。

来源 URL、路径、原始文件和快照保存在用户本地库中，应按资料自身敏感程度保护。返回给 Codex / ChatGPT 的检索片段与页面图片进入宿主上下文；“本地优先”不保证宿主推理离线。自动反刍由 Codex Scheduled 触发；本地内核提供存储和工作流。当前没有云模型客户端、公开服务器或隧道。

## 主张、确认与输出

认知写操作经 Application 事务提交，request_id 与规范化输入 hash 记录幂等结果；相同键不同内容拒绝提交。引用必须来自已保存块的精确字符片段，版本由块归属确定，不能接受调用方虚构页码或引用文本。关系类型不表示语义已经验证；模型置信度不能替代证据。

UserBelief 只有明确 confirmed 且 origin=human 才可保存确认时间；host_model 的确认请求拒绝。CLI 的 `--confirm` 是显式记录入口，不证明所有调用方陈述都真实，宿主仍必须遵守用户的实际指令。当前 MCP 不暴露该写操作。

队列预览与曝光写入分离。真正的展示、反馈和每天配额在事务内执行，防止并发超额或重复反馈；tick 默认不发通知。冲突候选引用已确认观点和显式证据关系，维持 possible_conflict 与 requires_user_review。

输出将标题、主张和原文按普通文本转义，避免其中的 HTML、Markdown 链接或代码成为输出指令。脚注使用真实版本、块和片段，原件链接只由经过校验的 CAS 路径生成。修订存储不可变快照，读取/导出核对引用与 Markdown，导出另校验原件 hash。发布目录使用服务生成 ID、no-follow 句柄及原子重命名；拒绝覆盖人工修改的文件。

## 可选 Provider 与备份

内置 NoLLM/Mock 不联网。自定义 Provider 属于显式安装和传入的本地 Python 代码；external 标记与 allow_external 约定网络调用权限；自定义代码具有所在 Python 进程的权限，需要由安装者审核。产品尚未提供云端 Provider 客户端。任务输入是有上限的保存块快照，返回最多五条 unverified 提议，引用必须匹配输入原文，不自动更新认知对象。

Provider 超时、失败与取消记录稳定状态，保留来源和原文；租约与 token 防旧任务覆盖新尝试。async 超时依赖协作取消，不能强制终止阻塞或不合作的自定义代码。

备份通过 SQLite online backup 获取一致快照。归档只含数据库快照、引用 blobs、结构化 records.json、已存输出重建文件和 manifest，不扫描任意用户目录，也不包含凭据配置。当前备份为未加密本地 ZIP，和源库一样需按材料敏感程度保存。

恢复拒绝路径穿越、绝对路径、符号链接、重复/未知条目、超限大小和异常压缩比；校验 manifest SHA256、数据库身份/迁移/外键、结构化记录一致性与引用原件。上限为 10000 条目、512 MiB 展开总量、256 MiB 数据库、20 MiB 单 blob、128 MiB records.json。目标必须尚不存在，验证完后独占发布目录，不覆盖或合并旧库。hash 校验检测内容损坏，不等于归档签名或来源认证。

## 本地浏览器与 MCP 写入

GUI 只绑定 127.0.0.1，检查 Host、Origin 与浏览器请求来源；POST 还要求随机会话令牌和 JSON 内容类型。响应不提供 CORS，页面限制脚本与网络为同源，禁止被 iframe 嵌入。上传只接收有大小上限的选中文件字节，保存内容快照后进入原有解析器；没有浏览器任意路径读取接口。原文和用户输入以文本呈现。

MCP 默认保持只读，显式开启 `RUMINATE_MCP_WRITES=1` 后提供写工具。写工具复用应用层的网络/文件范围、事务、幂等和审计；模型调用只生成 host_model 候选，不能确认用户立场。Annotations 是宿主提示，不代替应用校验。URL 导入仍需明确的网络授权且受网络模式限制。

删除影响预览、完整编辑管理与第三方导出授权仍待实现。公开报告应只引用必要短片段与元数据，本地保存 HTML/PDF 不等于获准全文公开再发布。
