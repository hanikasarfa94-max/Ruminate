# Support

- Start with the [README](README.md) and [usage guide](docs/USAGE.md).
- For plugin setup, see [Codex installation](docs/INSTALL.md).
- Check [known limitations](docs/KNOWN_LIMITATIONS.md) and [compatibility](docs/COMPATIBILITY.md).
- Use [GitHub Issues](https://github.com/hanikasarfa94-max/Ruminate/issues) for bugs,
  questions and feature requests. Include the Ruminate version, operating system,
  host version and a minimal example when relevant.
- Send security reports using [SECURITY.md](SECURITY.md).

English and Chinese are welcome. Ruminate is community-maintained, with no
commercial support contract or guaranteed response time.
